# 帳號版網頁語音輸入

首頁與 `/dictate` 使用個人帳號登入，呼叫既有 v2 排隊服務。介面提供大圓形錄音／停止、取消、明確的翻譯選單、原文、編輯、複製、清空與復原。每次錄音最多 110 秒，保留餘裕給服務端的 120 秒限制；檔案仍受 2 MiB 上限保護。

個人提示詞與詞庫由服務端帳號設定帶入；本次選擇的語言與模式在開始錄音時固定。網頁不提供任務執行或指令代理。帳號頁與 Android 原生鍵盤仍是獨立入口。

## 編輯個人偏好

在「我的帳號」登入，展開「個人詞庫與整理偏好」，即可編輯常用詞、個人整理提示與台灣縣市提示選項。提示詞最多 2,000 字、詞庫最多 1,000 字，沿用服務端限制。詞庫是辨識提示，不能保證正確，也不會強制把未說出的名字插入文字。

儲存只修改這三個欄位，保留翻譯語言、鍵盤用詞對照等其他設定。網頁帶上讀取時的版本；手機或另一分頁已修改時，伺服器以 412 拒絕舊版本，保留原設定。網頁保留草稿並提示先複製、載入最新設定再比對，沒有默默覆寫按鈕。重新載入或登出會先確認是否捨棄未儲存草稿；更新用量不影響草稿。

`GET /v2/me/preferences` 回傳設定與 `ETag`、`X-DreamType-Preferences-Version`。應用程式版本標頭可避免代理壓縮改寫 ETag 造成誤判；網頁使用此值送出 `If-Match`。附條件的 POST／PATCH 合併既有欄位，並在 SQLite 寫入交易中再次檢查版本。未帶條件的舊 Android 請求維持既有語意，**本次並未把所有舊手機客戶端改為衝突保護**。新設定只影響之後接受的錄音，重試中的工作仍使用原快照。

瀏覽器測試 `scripts/check_web_preferences.py` 包含版本衝突、保留草稿、用量更新不覆蓋、載入確認、代理弱化 ETag、條件式儲存及登出清除；後端 `test_preference_versions.py` 驗證部分更新、舊手機更新衝突與交易內版本重查。

## 中斷與結果

- 每筆錄音在上傳前產生請求代碼。上傳回應不明時，重試使用同一錄音、代碼與語言設定；不自動建立另一筆工作。
- 「取回上一筆」優先查詢本頁待確認的請求；沒有本頁錄音時才查詢帳號最近工作。
- 文字和回應模式驗證通過、顯示在編輯框後，才確認收件。收件確認失敗保留文字，另提供確認按鈕，不重送 AI 工作。
- 等待三分鐘後保留取回入口，不將仍在處理的工作誤報為失敗。主機仍有自己的總處理期限。
- 「放棄本頁重試錄音」只清除瀏覽器記憶體，不會取消已送達主機的工作。錄音中的「取消」則不會上傳。
- 已過期的服務端結果無法取回。頁面關閉前應複製文字；未送達主機的錄音無法跨頁恢復。

## 隱私與相容

登入憑證、音訊、編輯文字只留在分頁記憶體，不寫 localStorage、sessionStorage 或 IndexedDB。登出撤銷服務端憑證並清除本頁內容；登入世代檢查拒絕前一帳號的遲到回應。錄音與結果的服務端加密暫存、額度與隔離沿用 v2。

公開資源有 no-store、禁止嵌入及同源腳本政策；沒有外部字型、CDN、追蹤腳本或 HTML 注入結果。舊私人金鑰測試頁保留於 `/private`，既有 `/#key=...` 配對連結在瀏覽器內移至該入口。金鑰片段不會傳給網頁伺服器。

## 驗證範圍

`node --test outputs/local_voice/test_web_dictation.mjs` 驗證重試、帳號隔離、結果校驗及收件失敗。

`python -m unittest discover -s outputs/local_voice -p test_web_pages.py` 驗證路由、腳本 MIME 與安全標頭。

`scripts/check_web_workspace.py --output work/web-workspace` 使用 Playwright Chromium、合成麥克風與隔離的模擬 API，驗證登入、實際 MediaRecorder、同筆重試、收件確認重試、復原、取消、登出及 360 px 版面。可用 `--browser` 指定本機 Chrome。CI 保存桌面與手機寬度截圖。

這是瀏覽器客戶端驗證，不代表 Pixel 9 實機、真實行動網路、母語翻譯品質或付費上架驗收。主機仍由家用電腦提供；網頁本身不會在電腦離線時運算。
