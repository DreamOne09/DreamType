# 已辨識名稱的整理保護

2026-09-28：修正整理模型把第二次「板橋車站」改成「板橋車及」的已知案例。這是文字整理的名稱保留，不是語音辨識率提升，也不是完整地名辨識。

## 行為

- 僅在整理模式，把原文已出現的個人詞彙（2–40 字）與有限的目的地字串換成本次請求的暫存標記，整理後逐字還原。標記遺失、增生或順序改變會拒絕結果，語音路由仍退回辨識原文並顯示警告。
- 開啟台灣地名偏好時，使用既有縣市名稱，以及「到／回／去／在／從／往」後、以「車站／機場／醫院／大學」結尾的有限中文字串。這是保守字串規則，可能漏掉名稱或保留一般描述，不能辨識全部地名。沒有新增網路地名查詢。
- 只保留原文拼寫，不推測正確地點；ASR 已聽錯的名稱仍可能保留下來。個人詞彙仍可提供拼寫提示，但本功能不會把未出現的詞硬套入文章。
- 名稱中的英文採單字邊界；例如 GPT 不會遮住 GPT4 或 ChatGPT 的一部分。網址、電話、Email 的既有完整保護優先。
- 用既有嚴格規則處理可辨識的數量／時間改口，僅改本次送給整理模型的文字，不改 raw_text。其餘含「不對／不是／改成／改為／更正／口誤／說錯」的段落不啟用新增名稱保護；相鄰重複名稱也不鎖住，讓改口和口吃仍可整理。未支援的改口仍可能失敗，不能宣稱全覆蓋。
- 翻譯仍走原本的翻譯路徑；不新增名稱標記，避免強迫翻譯結果保留中文名稱。
