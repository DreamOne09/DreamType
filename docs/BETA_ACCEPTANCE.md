# 0.4.0 封閉試用驗收

更新：2026-09-21。「80%」在本輪指可交給少量受邀使用者試用的核心流程，不是商店上架完成度。原生手機操作仍須實機驗收；不以程式行數換算百分比。

## 已實作並驗證

| 能力 | 交付及證據 |
|---|---|
| 登入與登出 | 管理者建立帳號、密碼雜湊、七天登入、登出撤銷權限 |
| 每人獨立設定 | 提示詞、常用詞、台灣地名開關存入帳號；換手機登入可取回 |
| 排隊處理 | 單一工作者依入隊順序處理；最多八筆等待，同帳號只准一筆未完成工作 |
| 額度 | 按錄音秒數向上取整；UTC 每月統計；失敗不扣，重複請求不重扣 |
| 管理介面 | 建立帳號、查用量、改額度、停用；一般帳號無管理權限 |
| 帳號生命週期 | 修改密碼撤銷所有登入；使用者可輸入密碼刪除帳號及其設定、登入與用量紀錄 |
| 本機 AI | 家用主機實際 Whisper/Qwen；未接付費 API；保留推論服務轉接介面 |
| Android 套件 | 0.4.0，沿用套件與簽章；包含登入、用量、偏好、修改文字及 GitHub 更新入口 |

自動驗證：12 項 Python 測試通過；涵蓋權限、資料隔離、FIFO、重送、額度、停用、登出、密碼變更、刪除、重啟釋放額度與輸入限制。瀏覽器驗證管理頁建立／改額度／停用／離開管理，無 JavaScript 錯誤。

使用 APK 相同的 `VoiceApi.java` 在桌面 JVM 經現有 Cloudflare HTTPS 完成登入、偏好儲存、錄音排隊、查用量及刪除測試帳號。短錄音從送出至結果約 2.59 秒。**這是連線程式驗證，不是 Pixel 9 或 Surfshark／行動網路實測。**

## 下一階段，尚未完成

- 使用者決定先保留臨時通道，沒有固定網域；網址變更時需重新輸入服務網址並登入。
- 目前是邀請試用、手動額度，沒有 Google Play 訂閱、收款、退款、購買驗證或商店 AAB。
- 尚無長期多人壓力測試、備援、自動重啟及乾淨 Windows 重裝驗收。
- 手機目前不會在程序被結束後恢復工作；網路中斷後不自動重送錄音，避免多次提交。
- 商店版仍需公開刪除入口、隱私與 Data safety 文件、帳號恢復、Play 測試及正式更新流程。

## 管理與資料保存

啟動後執行 `work/venv/Scripts/python.exe scripts/admin.py`，開啟本機私人管理入口。建立每人獨立帳號，私下提供服務網址、帳號及初始密碼；不要提供管理者金鑰或舊版私人推論金鑰。受邀者可在 App 修改密碼。

資料庫位於 `work/beta/accounts.sqlite3`；存帳號、PBKDF2-HMAC-SHA256（600,000 次）密碼雜湊、登入 token 雜湊、偏好、用量與工作代碼，不存逐字稿或錄音。正常上傳可能有短暫磁碟暫存；排隊音訊在記憶體，結果只保留記憶體約 15 分鐘。成功結果過期或服務重啟後不能重新取回；成功用量仍保留。工作紀錄在服務啟動時清除超過 93 天資料。每月按 UTC 切換額度。

Android token 由 Keystore 加密保存；帳號密碼不保存；個人偏好會快取在 App 私有設定，關閉系統備份。登出清除本機偏好與登入。Cloudflare 可處理 HTTPS 代理流量，不是裝置間端對端加密。

備份與換機：先停止服務，再私下備份 `work/beta`、原推論金鑰及 Android 簽章；不放進 GitHub。新主機恢復檔案與模型，啟動後測試。遺失管理者金鑰時可在停機狀態刪除 `work/beta/admin.key` 讓服務重建，重新產生私人管理入口；不要刪除帳號資料庫。
