# 0.9.19 候選版：首次安裝的連線設定

登入與私人配對畫面，在尚未儲存服務網址時，預填這次打包時使用的公開服務網址。使用者仍須登入，或填入自己的專用金鑰；安裝檔不包含帳號、密碼或金鑰。既有的自訂網址會保留。

目前使用臨時 Cloudflare Tunnel，重新啟動連線可能換網址。因此這不是永久服務探索，也不會自動修復已安裝手機中的舊網址。固定網址仍需完成 dreamone.li 的 DNS 與 Tunnel 設定。

## 驗證

- JVM 測試涵蓋空設定、既有網址保留、HTTPS 格式與仍需憑證。
- 原生模擬器案例檢查登入及私人配對兩個實際畫面的預填、保留自訂網址，以及開啟畫面不儲存設定或建立登入。
- 原生案例尚待執行，候選 APK 尚未發布；Pixel 9 安裝與升級尚未實測。

## 詞庫仍待改善

目前個人詞庫會送入語音辨識提示，提示不保證模型一定採用。用詞對照則提供人工確認的修改建議。此版本未宣稱修復關鍵字準確率；需要正確詞與實際誤辨結果及語音測試，才可驗證改善，避免強制替換破壞原意。
