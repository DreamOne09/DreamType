# 敘述順序與長段回退（2026-09-28）

已加強整理提示，保留有意義句子的原本先後順序，不依主題重排，也不刪除隔著其他內容再次出現的句子。仍可刪口吃、採用明確改口的正確值及整理清單。原意／數字／否定／識別資料保護沒有放寬。

## 實際原因

對既有公開短音檔串接的 60 秒負載材料，擷取同一份辨識文字並重複整理。舊提示有時把「新電端……星球的大小」「開源服務」搬到最後，又刪掉一次人口老化句子；`Formatting exceeded faithful editing budget` 正確拒絕這種重寫，不是誤擋正確排版。

[保存的舊提示重跑](evidence/dictation-order/fragment-before.json)五次中一次被拒；較早探索也曾較頻繁拒絕，顯示單輪比例不穩定。[最終提示](evidence/dictation-order/fragment-after.json)五次均保留順序、非相鄰重複內容，通過原保護。這不是統計失敗率或自然長口述正確率。

素材來自既有 hash-verified 公開台灣短句音訊 manifest，串接本來就有不相關片段及辨識錯字；不把這份材料當成人類完整口述，也沒有為了通過測試修正辨識答案。此輪主要改善 formatter 的重排行為。

## 回歸與未通過項目

第一版新增的強硬順序提示曾讓模型照抄改口舊值與「第一／第二」標記，[失敗報告](evidence/dictation-order/chinese-first-attempt.json)保留。最終提示明確保留改口與列舉整理功能，另補強「第一銀行」是機構名、不是列舉標記的提示；有真正列舉時仍走列舉規則，有個人格式時仍由個人偏好控制。

最終 [19 件基礎](evidence/dictation-order/chinese.json)、[5 件較長文字](evidence/dictation-order/long.json)、[6 件個人提示邊界](evidence/dictation-order/personal.json)全部回傳 200，既有明確檢查通過。

新增六件獨立合成順序案例涵蓋交錯行程、非相鄰重複、被口述的請求、改口清單、重訪地點及同一主題重現。檢查器新增 ordered／occurrences，不只檢查關鍵字曾出現；臺／台的字形等價只在該案例的 ordered_aliases 明確允許。

[最終結果](evidence/dictation-order/sequence-after.json)為 **5/6 通過，1 件仍失敗**：第一件第二次「板橋車站交文件」變成「板橋車及交文件」。此問題在[舊提示基準](evidence/dictation-order/sequence-before.json)也存在，未由本修正解決。原本基準另有一件只因臺／台字形而標示失敗，原報告沒有事後改寫；最終用明確字形等價檢查。不能把六件全算通過，也不能宣稱專有地名均能保留。

來源沒有改為更好過的句子；錯字案例保留供下一步處理。語音 API 在保護規則拒絕時仍退回辨識原文，但這個單字錯誤目前低於通用改寫門檻，尚未被擋下。

正式家用主機已載入此提示，不需更新 APK。Pixel 9、自然長口述、更多口音、專有名詞保留、母語翻譯及與 Typeless 同音訊比较仍待驗收。
