# 上線狀態（2026-09-22）

目前是可下載的封閉測試產品，尚不能公開付費上線，也沒有證據證明整體比 Typeless 更好。本文彙整當前差距，歷史版本文件的完成項目不能代替這些門檻。

| 要求 | 已有證據 | 尚缺 |
|---|---|---|
| 台灣中文輸入 | 19 件基礎、5 件較長合成文字模型結果；台灣字形、個人排版偏好 | 真實台灣口述音訊、不同口音與長句、同批音訊與 Typeless 比較 |
| 多語翻譯 | 八種目標、模型與 JVM API 測試 | 各語言母語品質檢視及實機使用 |
| 手機體驗 | 0.9.3 APK；Android 16 模擬器首頁導向、Keystore、登出清除、離線隱私頁、密碼欄位保護，以及私人模式錄音上傳／固定繁中文字插入外部測試 App 通過（見 ANDROID_NATIVE_CI.md） | 帳號模式完整 UI 流程、Pixel 9 安裝升級、Keystore、輸入法、TalkBack、Surfshark 行動網路 |
| 多人使用 | 三帳號本機短錄音測試、跨帳號讀取拒絕 | 持續負載、長錄音／翻譯混用、外部網路容量 |
| 資料與恢復 | 加密資料、備份、刪除紀錄、程序突然退出及未提交交易回滾測試 | 真正離機備份與還原演練、備份保留政策、獨立安全審查 |
| 服務入口 | 家用主機、暫時 Cloudflare Tunnel | 固定入口、休眠／斷電可用性與外部離線通知 |
| 商店與付款 | APK、實驗 AAB 管線及官方要求規劃 | Play Console 帳號、商店測試、正式 Billing、伺服器購買驗證與退款同步、正式資料揭露 |

沒有付款接入前維持邀請免費試用；不以手機聲稱付款作為授權依據。沒有固定入口前，不宣稱「下載登入即用」已完成。

下一個最有價值的外部證據是 Pixel 9 驗收，以及選定離機備份位置；可先用 [手機驗收步驟](PIXEL9_ACCEPTANCE.md)，不需要 USB。
