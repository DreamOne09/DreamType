# 備份檔案盤點

管理頁的「備份檔案盤點」顯示本機備份檔數、相關檔案總容量、舊版 ZIP、未完成檔案、略過的連結及讀取錯誤。維護工作更新紀錄，超過 15 分鐘的盤點不視為正常。

盤點只讀檔案資訊，不讀取內容、不上傳、不刪除，也不跟隨符號連結或 Windows reparse point。只檢查備份目錄第一層；不包含其他資料夾。`.dtbackup` 副檔名僅用於計數，不能證明內容確實加密或可以還原；既有還原驗證仍獨立顯示。

發現舊版 ZIP、未完成檔、讀取錯誤或連結時，管理頁標示需要處理。舊版 ZIP 可能含有帳號資料和金鑰，應先確認可還原的加密替代備份，再決定如何處理原檔；本功能不會自行清除歷史備份。

自動保留期限、雲端上傳、異機還原及解密金鑰分開保管仍需另行完成，不能把盤點通過視為正式上線驗收通過。
