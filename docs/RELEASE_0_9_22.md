# 0.9.22-rc1 介面更新

已發布 [0.9.22-rc1](https://github.com/DreamOne09/DreamType/releases/tag/v0.9.22-rc1)，公開未登入下載的大小與雜湊核對一致。本版本仍為免費邀請測試；尚未通過商店或 Pixel 9 實機驗收。

## 操作變更

- 鍵盤以大圓鈕說話／停止／插入，搭配一致的向量圖示；錄音前後主按鈕保持原位。
- 錄音時計時與取消並排，取消不送出這次音訊。
- 退格、換行、復原、切換鍵盤都有固定入口；復原不可用時顯示停用狀態。
- 長按上滑翻譯保留，也可先點模式選擇語言，再開始說話。
- 首頁顯示帳號、麥克風、鍵盤三步。登入先填帳號密碼，網址收進連線設定。
- 個人設定固定底部儲存，長詞庫不用捲到底。
- 網頁採黑白介面、手機單欄與桌面並排結果；未啟用的 Google 登入入口隱藏。

## 驗證與限制

Chromium 隔離測試通過錄音、上傳／回執重試、取消、原文還原、復原、登出、320～1280 像素寬度、48px 按鈕、鍵盤操作及減少動態效果。正式固定網址另驗證登入頁正常載入、沒有 JavaScript 錯誤與橫向溢出。

[Play APK/AAB/lint](https://github.com/DreamOne09/DreamType/actions/runs/39495741142) 與 [Android 16 原生流程](https://github.com/DreamOne09/DreamType/actions/runs/39496603987) 均通過。原生驗證含固定錄音鈕位置、取消、翻譯手勢、插入／復原、密碼欄位保護、四種連線流程、回應遺失後恢復、固定設定儲存鈕與 1.3 倍字體的觸控區。Android 測試使用隔離帳號與合成文字 provider，不代表語音辨識準確率或 Pixel 9 真實操作驗收。

本輪正式服務僅更新網頁 UI，保留 schema 4、免費邀請登入與既有辨識／翻譯服務。沒有啟用 Google OAuth、付款或新增雲端推論。家用主機仍須在線；實機覆蓋安裝、TalkBack、Surfshark 行動網路與商店審核仍待驗收。

設計與操作規則見 [UI/UX 更新](UI_UX_2026_10_21.md)。
