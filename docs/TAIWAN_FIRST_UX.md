# 台灣中文優先的介面方向

DreamType 主要服務台灣中文使用者。預設說中文、整理成台灣繁體中文；翻譯是次要功能，需要時才展開語言選擇。

## 設計原則

- 參考 Typeless 的簡單操作與資訊層級，使用 DreamType 自己的名稱與圖像。
- 主操作保持「按下錄音 → 說話 → 確認文字 → 插入」。
- 黑白灰為主、充足留白、大按鈕；狀態以清楚的中文說明，不能只靠顏色。
- 鍵盤優先呈現錄音及結果；個人提示詞、詞彙、帳號、更新放到設定。
- 使用「開始說話」「正在整理」「修改文字」「插入」等日常文字，避免把模型與伺服器術語放到主要流程。
- 台灣地名、人名、中英夾雜、改口與否定是品質核心；個人排版偏好優先於預設格式，但不得新增事實。

## 驗收界線

上述為產品方向，不代表所有畫面已完成重新設計。現有 Android 已採繁體中文、黑白灰、中文整理預設及次要翻譯入口；視覺比例、單手操作與不同 App 的插入體驗仍須 Pixel 9 實測。

## 主畫面簡化（2026-09-22，尚未發佈 APK）

- 主畫面由四個大型入口收斂為一個當前步驟的主要按鈕，以及「設定與帳號」選單。選單保留排版、帳號、隱私與進階連線入口。
- 啟用鍵盤後，主操作為「選擇 DreamType 鍵盤」，直接開啟 Android 鍵盤選擇器，不先等待網路健康檢查；錄音送出仍沿用既有連線錯誤與重試處理。
- 主畫面按鈕使用最小高度加自適應高度，避免大字體受固定高度限制；標題使用自然換行。
- 提示文字明確區分預設確認與可選擇的直接插入，不再宣稱所有結果都一定經過確認。

全部 Android Java 原始碼已用 API 36 編譯通過。這僅驗證編譯，未驗證 Pixel 9 的實際外觀、TalkBack、放大字體或鍵盤選擇器互動。現有 v0.9.0-rc1 下載內容未更動；此修改留待下一個測試版打包。
