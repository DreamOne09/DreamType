# 中英夾雜的整理保護

整理階段原先只特別保護中文否定／條件詞，英文 `not → now` 或 `cannot → can` 可能落在允許的小幅修改範圍內。現在在刪除標點空白前識別英文詞界，將 not、no、never、unless、only、until、before、after、must、cannot 及常見否定縮寫的位置映射到既有文字對齊，拒絕這些位置的新增、刪除、替換或移動。

保留大小寫及直／彎引號的排版變化，不把 notebook 內的 not 當否定詞。中文連續口吃清理仍可使用。此規則保守：語意等價但拼寫不同的否定改寫也可能退回原文。

49 組整理保護、口述改口及個人化測試通過。這是文字變更防線，並非完整語意解析；辨識本身把 can not 聽成 can now 時，無法靠此檢查修復。翻譯也不套用這個同語言文字對齊規則。
