# 試用版資料說明入口

待發布 Android 原始碼與實驗 AAB 新增「資料與隱私」頁，首頁及帳號頁皆可開啟，不需要登入或網路。尚未更新 GitHub 0.8.0 已發布 APK，不能宣稱使用者手機已收到新頁面。

內容依目前實作說明：錄音上傳到設定的服務主機、Cloudflare HTTPS 代理的界線、帳號／偏好保存、加密待處理錄音與 15 分鐘結果、手機一小時重試錄音、刪除帳號、歴史備份及保留刪除 ID 的原因。首頁請求麥克風權限前也顯示遠端傳輸用途。

手機刪除确认與網頁 `/account` 已說明備份不會立即改寫；不能將「刪除線上帳號」說成刪除所有歷史備份。Web 文字已在家中服務更新，Android 仍待下一次正式 APK 發布與實機驗收。

這是目前免費邀請試用的事實說明，**不是已完成法律審閱或 Google Play 審查的隱私政策**。公開上架前仍需營運者身分與聯絡方式、可穩定公開存取的政策與刪除入口、確定的備份保留期限，以及與實際功能一致的商店資料安全申報。

验证：實驗 AAB 簽署、bundletool validate 與衍生 APK 簽章驗證通過。原生頁面的 Pixel 9 排版、字級縮放及返回行為尚未實測。
