# DreamType 品牌診斷：中文編輯室

2026-10-21，概念稿第二版；未部署正式網站或 APK。

## 使用的來源與範圍

原始專案：https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

已閱讀原始專案說明，並使用已安裝的 UI UX Pro Max 技能與本機搜尋程式。查詢 `editorial typography minimal --domain style` 命中 Minimalism & Swiss Style：清楚文字層級、留白、格線、少漸層與裝飾陰影，以及對比與鍵盤操作檢查。這些是品質規則，不是自動保證品牌獨特的評分器。

以下模板感的判斷與「中文編輯室」方向是本次設計判斷，不是 repo 的自動評分，也未經使用者研究驗證。

## 第一版的問題與這次修改

| 問題 | 修改 |
|---|---|
| 幾乎所有區塊都用相似圓角容器，缺少閱讀節奏 | 比較區改成細線分欄；宣傳區改成平直版面；圓形保留給主要錄音操作 |
| 青藍、淡紫、重疊圓形可套到許多產品 | 以中文全形引號、逗號和句號作識別，連結真實產品用途 |
| 標題與操作文字氣質接近 | 宣傳標題用本機明體／宋體字系，操作保留黑體，兼顧表達與易讀 |
| 宣傳文字過於抽象 | 使用「欸，我跟你說」「等一下，讓我把這個想法說完」等台灣日常語句 |
| 增加個性容易變成到處加裝飾 | 暖紙底、莓粉校稿線集中在品牌區；鍵盤維持白底與清楚操作 |

## 識別規則

- 主色深青藍 #087E83；紙色 #F8F5EF；校稿莓粉 #A53160；深墨 #173337。
- 引號框住人的話；底線只標記一個重點。不可在每個按鈕加引號或貼紙。
- D 聲波繼續作小尺寸圖示。不要強行把所有新元素塞進 App icon。
- 錄音／停止、取消、刪除、復原保留固定位置及文字。長按選單另有可點的模式入口。
- 不加沒有功能的漂浮星星、循環聲波動畫或模糊光暈。
- 明體依設備可用字體回退；正式落地前需選定可合法隨 App 發布的中文字型並在 Android 驗證。本稿不宣稱跨平台字型完全一致。
