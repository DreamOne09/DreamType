# DreamType：下一階段交付

日期：2026-10-21。定位：台灣繁中優先的語音輸入工具，協助整理與翻譯，不擅自執行口述內容中的指令。

## 推薦品牌方向

採用「曉光青藍」：深青藍 #087E83 為主要操作色、淡青 #E8F5F3 為襯底、淡紫 #DCD5F3 為宣傳輔色。文字 #173337，背景 #FAFCFB。

Dream 的連結放在「讓想法醒來，讓文字成形」的文字與晨光般的輔色；標誌延續 D 與聲波。避免同時增加月亮、雲、星星，讓小圖示仍清楚。

玫瑰粉適合更強烈的創辦人品牌；夢境紫與名稱的連結直接。三者均在 index.html 提供可切換的預覽，尚未決定或套用到正式 App。

## 這一批已交付

- 三款配色、可互動鍵盤概念、宣傳橫幅與標誌尺寸比較。
- 固定位置的大圓形錄音／停止操作，以及取消、刪除、復原與語言選單概念。
- 可重用的配色檔與 SVG 圖示。

此頁使用固定範例，不錄音、不連線，不代表真實辨識或翻譯品質。既有 APK、正式網站與備份設定未因本次概念稿改動。

## 下一個產品層級：可交給陌生人試用

1. 統一 Android、網頁、下載頁及商店素材的色彩、圖示和詞彙；錄音狀態同時用圖示與文字表達。
2. 新使用者能自行安裝、登入、啟用鍵盤並完成第一次輸入；既有使用者升級後能正確處理舊服務網址。
3. 在 Pixel 9、行動網路與 Surfshark 下驗證：中斷重試、取消不插入、刪除及復原、長按翻譯、跨 App 輸入。
4. 用經同意的台灣口音樣本驗證地名、專有名詞、全形標點、分段與列點；記錄正確率、延遲及失敗案例。不得只憑示意畫面宣稱辨識提升。
5. 驗證「請幫我生成計畫」只被整理成文字，不被當成模型執行指令；翻譯保留原意。

## 正式收費前仍須通過

- 家中主機故障時有告警與可操作的復原程序；固定網址不等於運算服務不中斷。
- R2 備份可在另一台機器完整還原，復原金鑰另行保管。R2 是備份空間，不是語音辨識伺服器。
- 完成帳號復原、資料刪除、客服與資料處理說明。
- 建立 Play 開發者帳號，完成正式簽章、實機驗證、付款／退款與所需上架流程。
