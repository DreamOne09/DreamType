# 整體視覺複查

本輪範圍：品牌預覽的桌面與手機畫面。原生 App 僅有先前建置證據，未有本輪原生畫面實測；不能把 HTML 示意當成 Pixel 驗收。

主要問題是樣式疊加：明體大標與柔粉不協調、粉色邊線過多、深綠橫幅過重、配色選擇與說明搶走產品層級。這些是設計判斷，並非使用者研究結果。

已重整整份 CSS，移除重複覆蓋；統一黑體、暖白底、柔粉重點、灰綠分隔線；配色與品牌細節改成可展開區塊。大圓鈕與取消、復原、語言選單保留。舊版保留於 before-polish.html。

UI UX Pro Max 首次 UX 查詢沒有命中視覺層級，未採用其麵包屑建議；改用 style/minimalism 搜尋確認留白、文字層級與一致性方向。

驗證：320、390、768、1280 px 與橫向 844×390；收合與展開狀態無橫向溢位。錄音、取消、插入、復原、鍵盤開啟語言選單、長按選單通過，無 JS 執行錯誤。已檢視桌面與手機截圖。本輪不改候選 APK，不發布正式下載。
