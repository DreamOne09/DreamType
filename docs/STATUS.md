# 0.2.0 試用版

## 已完成
- 黑白灰色系，移除綠色品牌色，DreamType 名稱與圖示。
- 已設定的連線區塊預設收起，清楚區分連線、錄音權限與啟用鍵盤。
- 原生 APK 編譯、v2/v3 簽章驗證通過；沿用 0.1.0 憑證與套件名稱。
- 先前手機網頁語音流程已由使用者確認速度可接受。

## 尚未驗證 / 限制
- 0.2.0 原生版尚未在 Pixel 9、模擬器或其他裝置視覺驗收。大字體、橫向、來電中斷、長時間使用仍待實測。
- 新電腦安裝腳本尚未在乾淨 Windows 上完整重裝驗證。既有 NVIDIA 電腦上的引擎已驗證。
- 每段錄音最多 2 分鐘，失敗不自動重送。
- 電腦需保持開啟；預設臨時通道變更時需重新配對，沒有固定自動探索服務。
- 現有模式以忠實整理為目標。「需求說明最佳化」的專用模式尚未實作，不自動補寫需求。
- 不支援 iPhone 原生鍵盤。

## 隱私
金鑰在 Android Keystore 加密儲存，不嵌入 APK；不要求無障礙或聯絡人權限。音檔暫存正常完成或取消後刪除；系統強制終止時可能殘留快取。伺服器上傳處理可能短暫使用磁碟暫存，不是完全無磁碟流程。HTTPS 通道由 Cloudflare 代理。
