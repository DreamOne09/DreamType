加入新的 D 聲波向量 logo、自適應和單色主題圖示，以及依設定狀態引導的首頁。鍵盤改為依狀態顯示主要動作，其他功能收進更多選單。新版 APK 編譯與簽章檢查通過，logo 向量预览已檢視；新版首頁、選單、圖示在 Pixel Launcher 的實際顯示仍待實機驗收。

# 0.3.0 試用版

已加入：每支手機的個人提示詞與常用詞库、台灣地名參考開關、App 內管理頁、GitHub 更新檢查、修改文字與捨棄草稿。

## 驗證
- Android 原生 APK 編譯與 v2/v3 簽章檢查通過，沿用原套件及憑證。
- 5 項 Python 測試通過：多個使用者請求隔離、長度與型別限制、授權、錄音整理失敗時保留原文、地名開關。
- Java 更新比較測試通過，含 0.9 → 0.10、同版不更新、避免降版、排除預覽版本；已查詢真實 GitHub API。
- 已用本機模型測試兩種個人排版提示、汐止與板橋地名文字，以及 M4A 語音辨識；這不是各地名口音的準確率測試。

## 仍需驗收
- 原生鍵盤、管理與編輯畫面尚待 Pixel 9 實機驗收，未驗證旋轉、大字體、來電中斷等情況。
- 新電腦安裝腳本未在乾淨 Windows 完整重裝驗證；目前支援 Windows NVIDIA 配置。
- 台灣地名參考不是完整地址資料庫，不保證每個鄉鎮、道路或同音字辨識正確。
- 偏好以手機區分，没有多人帳號、管理員權限、跨手機同步。共用電腦服務的金鑰亦不是獨立帳號憑證。
- 更新檢查開啟 GitHub 下載，由 Android 確認安裝；不會自動更新電腦模型或後端。
- 每段錄音最多 2 分鐘。編輯草稿僅存記憶體，程序被系統結束會消失；請在送出前確認。
- 電腦需開著，通道網址改變時需重新配對。不支援 iPhone。
- 保留原意，不自動補寫未提及的需求。

## 資料與隱私
縣市名稱參考：[中華郵政](https://www.post.gov.tw/post/internet/Download/index.jsp?ID=220306)。自訂詞庫與提示詞由使用者提供，每次請求獨立處理，不記錄為伺服器上的個人檔案。
金鑰由 Android Keystore 加密保存；偏好存在 App 私有設定內，備份關閉。錄音經 Cloudflare 代理，不是裝置間端對端加密。正常完成或取消後清除暫存音檔；伺服器上傳可能短暫使用磁碟暫存。
