# 用詞建議中的引文保護

0.9.16 修改 Android 本機建議；必須安裝新版 APK 才生效，單獨更新電腦端不會改變手機的這個功能。

原版只保護部分引號，對 `“軟件”`、`《軟件設計》`、未完成的 `「軟件` 仍提出替換。新增測試先在原程式重現失敗，再加入配對掃描，保護直角引號、雙／單彎引號、雙引號、書名號及巢狀引文；尚未閉合時保留直到文字末尾。程式區塊及網址保持保護，網址後的中文分隔符不再把一般文字一起吞入網址。

引文關閉後，後面的普通詞彙繼續提供建議。建議仍必須點選才套用，可復原或取消；沒有加入輸入歷史學習或人名辨識。未加引號的名稱若包含固定詞表字詞，仍可能收到建議，使用者可保留原文。

JVM 測試涵蓋既有個人對照、長詞優先、英文字邊界、引文與未完成文字，以及關閉引號後重新提供建議。原生修改頁測試加入 `“軟件”` 及 `《硬件設計》`，要求建議數仍為兩筆，接受後只改一處，復原、取消及過期草稿保護仍有效。

APK 使用既有套件 `tw.localvoice.keyboard`、versionCode 26，維護者簽章 SHA256 `8af01d69be8604c2f4a288d55651bb72bed42a391c546f04db4a2a0deb14fc98`。檔案 SHA256 `50579812cd6e2b1a3436f12b5b4c44db42ce0b3089d49bd4ca9453bbe5fe770b`。

[原生工作 36427694524](https://github.com/DreamOne09/DreamType/actions/runs/36427694524) 在功能提交 b8f49f7 通過（6 分 25 秒）。[結果](evidence/android-0.9.16/result.txt) 包含建議、個人對照、帳號隔離及跨程序錄音保留；四條鍵盤流程亦通過，AI 使用合成回應。

[套用後畫面](evidence/android-0.9.16/suggestions-applied.png) 確認引文保留。底部 Toast 來自前一個過期草稿測試，遮住部分按鈕，不能以此宣稱所有 UI 狀態均驗收。

0.9.16-rc1 已公開；公開下載資產 SHA256 與上述本機值一致，保留為 prerelease，未取代穩定 latest。Pixel 9、Surfshark、實際升級和真人語音仍未驗收。
