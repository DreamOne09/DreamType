# 加密備份複製核對

2026-09-28：維護程式現在於覆蓋目的地前，串流計算來源與暫存副本的 SHA256。只有完整內容相符才以既有原子替換發布副本。靜默截斷、內容損壞或讀取失敗會保留目的地的上一份檔案，移除本次暫存，並回報維護錯誤。來源與目的地相同會拒絕，不再把「沒有另存」當作複製成功。

只核對加密檔的位元組，不解密到硬碟、不改正式資料庫、不刪除歷史備份。這不保證斷電後硬碟耐久性、雲端已上傳或異機可還原。

成功才記錄 last_backup_copy_verified、backup_copy_verified_file 與 last_deletion_copy_verified。管理摘要要求目前備份檔名一致、核對時間吻合，以及刪除副本對應最新匯出；舊版只有複製時間的紀錄顯示待核對。即使成功，異機備援狀態仍為 unverified。

另外修正管理頁原本「在隔離目錄成功還原」的過時文字：目前驗證實際是在記憶體進行還原準備，不應聲稱寫入過另一個目錄。

10 項維護測試、6 項管理狀態測試通過。新增損壞備份／刪除紀錄、核對讀取失敗、原地複製、舊紀錄與新備份不一致等案例；錯誤都不得覆蓋舊副本或新增已驗證紀錄。

[本機實測](evidence/backup-copy.json)：使用主機現有加密備份複製到暫存目錄，核對後以目前刪除紀錄在記憶體驗證還原；未替換正式資料庫。暫存副本於測試後清理，證據只保存布林結果與檔案大小，不包含備份、金鑰或帳號內容。

目前沒有 backup-config.json，沒有設定雲端目的地，沒有上傳。真正離機還原、金鑰異地保管與備份保留政策仍未完成。
