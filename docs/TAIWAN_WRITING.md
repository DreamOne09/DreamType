# 繁體中文排版與用詞建議

0.9.12 預覽版加入以下行為：

- 整理模式要求依句意斷句，同一主題保持同段，轉換主題才分段；短訊息不逐句換行。列舉仍逐項分行，個人單段偏好優先。
- 中文敘述加上確定性的全形標點整理。保留網址、電子郵件、數字分隔符、反引號程式碼與英文引文；原始辨識文字仍可還原。翻譯成繁中也使用此整理。
- Android 偵測到內建詞表的台灣常用替代說法時，在「修改」顯示建議數量；進入修改頁可選擇套用單一出現位置，或保留原文。「復原這次修改」仍可撤回全部編輯。
- 目前詞表包括軟件／軟體、硬件／硬體、鼠標／滑鼠、打印機／印表機、視頻／影片、默認／預設、文件夾／資料夾、服務器／伺服器、計劃／計畫。這些是可選替代說法，不代表原文錯誤。引文、網址及程式碼不提出建議。

詞彙判斷在手機記憶體進行，不收集打字紀錄、不保存詞頻、不跨帳號學習，也不呼叫 LLM 生成建議。尚未實作依個人歷史學習詞庫。專有名詞與特殊語境仍由使用者判斷；不自動替換、不回答或執行口述要求。

分段語意仍由模型判斷，不能保證每一段都正確。單元測試與 JVM 合約涵蓋標點、識別資料保留、建議位置及引用排除；APK 編譯不代表 Pixel 9 的介面已實測。

## 0.9.13 個人用詞對照

「我的 DreamType → 我的用詞建議」每行填 `原詞 → 慣用寫法`，例如 `夢想型態 → DreamType`。最多 20 組、每側 40 字，整欄最多 1,000 字。刪除一組並儲存即可停止該建議。既有「常用地名與人名」仍是辨識參考，兩者用途不同。

原詞出現在暫存文字時，「修改」顯示建議數量。點選只改一處，可以保留原文、復原或取消。個人對照優先於同原詞的內建建議；重疊對照優先較長詞，避免同一範圍出現矛盾建議。英文／數字詞不匹配較長識別字中的一部分。引文、網址及反引號程式碼沿用保護。

帳號模式儲存在既有帳號 preferences JSON，登入或同步偏好後可在另一裝置取回；不需資料庫欄位遷移。舊版 App 儲存其他偏好時不會清除新對照。登出清除手機副本；主機副本隨帳號刪除流程處理。私人連線模式只保存在手機。對照不送給推論服務、不作指令或自動替換，也不從錄音／輸入歷史偷偷學習。若啟用「完成後直接插入」，仍不會自動套用建議。

本次驗證：24 項帳號 API 測試及 8 組 Android JVM 合約通過；[原生模擬器測試已通過](ANDROID_NATIVE_CI.md)，涵蓋個人對照點選、復原及登出時的過期對話框。Pixel 9 實機尚未驗收。

## 修改頁設定讀取

0.9.15 原始碼將每次編輯的建議計數與選單改為直接讀取用詞偏好，不再為此解密登入憑證。與偏好儲存／登出共用鎖，不保留可能過期的獨立詞庫快取；套用建議、還原辨識原文與儲存仍檢查登入及草稿狀態。這消除每次按鍵的 Keystore 工作，但尚無 Pixel 9 實測加速數據。
