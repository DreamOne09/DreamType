# Pixel 9：0.9.10 候選版驗收

這是測試版，0.9.9 的 Android 16 模擬器已有部分原生證據，但仍未完成 Pixel 9 實機驗收；0.9.10 的新增連線重試另有 JVM 故障注入測試。測試用記事本或空白草稿，不要用真實聯絡人聊天來試發送。

## 安裝前

先完成或清除尚未交付的錄音。保存管理者提供的登入／連線資訊。候選版 package 和簽章與 0.8.0 相同，versionCode 20；安裝器應顯示更新。若要求移除舊版或回報簽章不符，停止，不要先刪除 App。

Android 通常不允許直接以較低版號覆蓋，候選版不是一鍵可降版更新。不要為測試自行清空尚未保存的錄音與設定。

## 約十分鐘檢查

1. 開啟首頁，從「設定與帳號」讀取「資料與隱私」，切換飛航模式再開啟，確認仍可閱讀；完成後恢復行動網路與 Surfshark。
2. 查看首頁、帳號、設定與資料說明，確認頂端與底端按鈕沒有被系統列遮住，系統返回手勢可回上一頁。
3. 在記事本切換 DreamType。說「明天下午三點，不對四點半，在板橋車站見，不要去台北車站」。確認時間改口與否定保留，先檢查再插入。
4. 說「第一明天早上買牛奶，第二下午幫媽媽拿藥，如果下雨就一起延到後天」。確認清單分項、共用條件沒有只套到最後一項。
5. 切換翻譯成日文，再回到整理模式。每次結果應符合當次選擇，不沿用上一筆語言。
6. 在一段錄音上傳後短暫切換網路，確認介面不當機，可取回上一筆或手動重試；檢查用量沒有重複扣除。無法取回時記下訊息，不要連續另錄多筆。
7. 放大系統字級、橫向顯示、切換其他 App 後回來，檢查按鈕與長文字能看清、捲動與編輯。測完可恢復原設定。

回報格式：Android 版本、DreamType 版本、通過的步驟、失敗步驟與畫面文字。不要回傳密碼、金鑰、真實私人錄音或登入頁配對網址。

## 本機驗收限制

2026-09-22 唯讀檢查：本次開發主機的韌體虛擬化未啟用，HypervisorPresent=false，C 槽約剩 2.8 GiB；因此未下載或啟動 Android 模擬器。D 槽容量足夠，但不能替代啟用虛擬化所需的 BIOS 設定與重新開機。本次沒有更改 BIOS／Windows 虛擬化功能。

模擬器或手機未實際完成以上操作前，不能把編譯、bundletool 或 Java HTTPS 測試當作原生裝置驗收。

## 0.9.2 補充

若測試時遇到上傳失敗而留下可重試錄音，可到設定改選另一個翻譯目標，再回原 App 重試；結果應仍符合該段錄音原本的目標語言。只用無私人資訊的測試句，且先確認上一筆已插入或捨棄。若沒有產生失敗，不必刻意重複斷網；此項標記未測即可。舊版保留錄音沒有語言快照，新版會提示先取回結果，不能直接重傳。

## GitHub 模擬器已補部分證據

2026-09-22 已在 GitHub 的 Android 16 模擬器實際驗證首頁登入導向、Android Keystore 憑證及合成錄音讀寫、登出清除、離線隱私頁、密碼欄位保護，以及私人模式錄音上傳／固定繁中回覆插入獨立測試 App，見 [原生模擬器驗證](ANDROID_NATIVE_CI.md)。本機韌體限制沒有被變更；遠端模擬器不等於 Pixel 9，也未驗證真實語音品質、帳號模式完整 UI 流程及 Surfshark。

## 0.9.5 更新選項

在「我的用語與排版 → 連線與更新」確認「更新時包含測試版」預設關閉。開啟後檢查更新，關閉頁面再回來，選擇應保留。沒有更高版本時應顯示所選頻道；有新版時先完成未交付文字，再開啟該版本頁面。此項仍需手機實測。

## 0.9.6 修改頁

先修改一段測試文字，旋轉手機，確認修改仍在；按「復原這次修改」應回原文。完成後返回原 App 插入。模擬器已測 Activity 重建，實際旋轉、Gboard 彈出時的版面仍需 Pixel 9 驗收。程序被 Android 關閉後，未完成修改可能遺失；此版本不是永久草稿。


## 0.9.8 圓形鍵盤與翻譯

1. 在記事本點中央「說話」，說「明天下午四點半到板橋」，按「停止」，確認後按「插入」。
2. 點右側退格刪一字，再長按連刪；選取文字後再按退格，確認只刪除選取內容。
3. 長按「說話」往上滑到英文，放開，說一句中文，再按停止。確認翻譯結果與目前目標一致。
4. 也可點上方模式選單回到「整理成台灣繁中」。測試日文、泰文、馬來文時，請保留原意是否正確的人工檢查。
5. 開著 Surfshark、使用行動網路完成同一流程。模擬器通過不能代替此項實機驗收。

新版保留原有設定；直接覆蓋安裝，不要先解除安裝。更新前先處理未完成錄音。


## 0.9.9 原文還原與撤回

1. 說「請幫我生成一個計畫」。結果應保留這句要求，不能自己寫出計畫。
2. 結果出現後，若整理改變文字，可按「還原原文」回到語音辨識文字；它不能修正辨識本身的錯字。
3. 按「修改」調整文字，再取消修改；原結果應保留。插入記事本後，按「復原剛才輸入」撤回這次插入。
4. 如果原本選取了一段文字，插入後立即復原，應恢復原先選取的文字。移動游標、改動內容或切換輸入欄位後，復原可能停用，以免刪到其他文字。

## 0.9.10 取回上一筆的連線恢復

「更多 → 取回上一筆」的首次唯讀查詢若暫時斷線或遇到 5xx，現在最多重試三次（合計四次請求）；401 等 4xx 不重試，請依訊息重新登入。後續輪詢原有的有限重試保留，整個取回流程不重送錄音。持續失敗仍會顯示錯誤，不保證離線也能取得結果。

手機驗收時若首次查詢剛好遇到網路切換，確認能顯示重連狀態，恢復後取得同一筆結果；無法重現可標記未測，不必多次錄音。JVM HTTP 故障注入已覆蓋首次 503、持續 502、首次及後續 401，但不能代替 Surfshark 行動網路實測。
