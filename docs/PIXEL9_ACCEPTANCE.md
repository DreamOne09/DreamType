# Pixel 9：0.9.2 候選版驗收

這是測試版，尚未完成 Android 16 原生驗收。測試用記事本或空白草稿，不要用真實聯絡人聊天來試發送。

## 安裝前

先完成或清除尚未交付的錄音。保存管理者提供的登入／連線資訊。候選版 package 和簽章與 0.8.0 相同，versionCode 12；安裝器應顯示更新。若要求移除舊版或回報簽章不符，停止，不要先刪除 App。

Android 通常不允許直接以較低版號覆蓋，候選版不是一鍵可降版更新。不要為測試自行清空尚未保存的錄音與設定。

## 約十分鐘檢查

1. 開啟首頁，從「設定與帳號」讀取「資料與隱私」，切換飛航模式再開啟，確認仍可閱讀；完成後恢復行動網路與 Surfshark。
2. 查看首頁、帳號、設定與資料說明，確認頂端與底端按鈕沒有被系統列遮住，系統返回手勢可回上一頁。
3. 在記事本切換 DreamType。說「明天下午三點，不對四點半，在板橋車站見，不要去台北車站」。確認時間改口與否定保留，先檢查再插入。
4. 說「第一明天早上買牛奶，第二下午幫媽媽拿藥，如果下雨就一起延到後天」。確認清單分項、共用條件沒有只套到最後一項。
5. 切換翻譯成日文，再回到整理模式。每次結果應符合當次選擇，不沿用上一筆語言。
6. 在一段錄音上傳後短暫切換網路，確認介面不當機，可取回上一筆或手動重試；檢查用量沒有重複扣除。無法取回時記下訊息，不要連續另錄多筆。
7. 放大系統字級、橫向顯示、切換其他 App 後回來，檢查按鈕與長文字能看清、捲動與編輯。測完可恢復原設定。

回報格式：Android 版本、DreamType 版本、通過的步驟、失敗步驟與畫面文字。不要回傳密碼、金鑰、真實私人錄音或登入頁配對網址。

## 本機驗收限制

2026-09-22 唯讀檢查：本次開發主機的韌體虛擬化未啟用，HypervisorPresent=false，C 槽約剩 2.8 GiB；因此未下載或啟動 Android 模擬器。D 槽容量足夠，但不能替代啟用虛擬化所需的 BIOS 設定與重新開機。本次沒有更改 BIOS／Windows 虛擬化功能。

模擬器或手機未實際完成以上操作前，不能把編譯、bundletool 或 Java HTTPS 測試當作原生裝置驗收。

## 0.9.2 補充

若測試時遇到上傳失敗而留下可重試錄音，可到設定改選另一個翻譯目標，再回原 App 重試；結果應仍符合該段錄音原本的目標語言。只用無私人資訊的測試句，且先確認上一筆已插入或捨棄。若沒有產生失敗，不必刻意重複斷網；此項標記未測即可。舊版保留錄音沒有語言快照，新版會提示先取回結果，不能直接重傳。
