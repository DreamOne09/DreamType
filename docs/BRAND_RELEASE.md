# 花瓣粉介面更新

本次同步 Android 原生共用按鈕、錄音圓鈕、啟動圖示與頁面底色，以及網頁 dictation 工作區的主色。主色 #F5A9C5、墨綠字 #153D35、暖白底 #FCFBF9；保持原有操作及登入協定。

最新版互動品牌預覽位於 [docs/brand-preview/index.html](brand-preview/index.html)，下載 repo 後可直接開啟。預覽是固定範例，不代表辨識或翻譯實測。歷史診斷文件中的「未套用」描述僅指當時那一輪。

原生建置與簽章驗證通過，但 Pixel 9 外觀與操作尚待驗證。推送 main 不會自動替換家中服務或使用者手機上的 APK。正式下載版本需另經發布流程；請勿把候選 APK 或 main 提交當作已部署證據。
