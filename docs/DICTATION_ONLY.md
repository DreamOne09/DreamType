# 語音輸入，不代替使用者回答

DreamType 的整理模式只整理使用者口述內容。「請幫我生成一個計劃」應保留成這句要求，不能產生計劃。未加入代寫或執行助理模式。LLM 仍負責標點和排版；翻譯只有明確選擇翻譯模式時進行。

## 0.9.9 修正

- 辨識原文以 JSON transcript 資料欄位送入模型，系統指示明確限制口述及個人偏好不能要求模型作答或擴寫。
- 整理後檢查文字變動量（忽略標點／空白）：新增最多原文 15%、刪除最多 30%，短句容許一字。超過時音訊 API 回傳完整辨識原文並顯示排版失敗提示；私人文字整理 API 回傳 503，避免替換原文。
- 這是保守的文字檢查，不是完整語意驗證。小幅但錯誤的改寫仍可能通過；大幅合理改寫則可能被退回。因此保留可人工還原的原文，不能宣稱永不改錯。
- Android 預覽新增「還原原文」，編輯頁新增「還原辨識原文」及「取消修改」。原文取自伺服器既有 raw_text；舊伺服器沒有原文時不冒充原文。翻譯也可還原來源辨識文字。
- 插入後新增「復原剛才輸入」，保留預覽並恢復原本被取代的選取文字。只在同一登入、同一輸入工作階段、游標位置與剛才插入內容一致時執行。改過文字／移動游標後不自動刪除；不支援提供不了必要 InputConnection 資訊的 App。
- 手機原文只保留於既有暫存記憶體，不寫入偏好、日誌或 Activity saved state；新錄音、捨棄與登入切換清除。帳號結果沿用伺服器加密 15 分鐘結果保存政策，沒有新增保存期限。
