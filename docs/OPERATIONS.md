# 管理頁的維運狀態

登入 `/admin` 後，按「重新整理」取得狀態。頁面以繁體中文分別顯示自動維護、語音與翻譯服務、手機通道、本機加密備份、刪除紀錄、異機備援。

- 維護紀錄超過 15 分鐘、缺失或時間無效，不會沿用舊的健康結果宣稱服務正常。
- 模型與通道狀態來自最近一次維護檢查，不是頁面即時探測，也不代表使用者端連線品質。
- 本機備份超過 36 小時沒有成功紀錄會提示處理；刪除紀錄超過 15 分鐘沒有匯出亦會提示。
- 同步資料夾只表示本機檔案複製。即使備份與刪除紀錄都有複製成功時間，異機備援仍標為「尚未驗證」，不能當作雲端上傳或救災驗收。
- 主機恢復、通道恢復、備份與刪除紀錄匯出等錯誤會轉為中文說明。未知錯誤不直接回顯任意檔案內容。

這些資訊由管理者專用 `/v2/admin/metrics` 提供；一般帳號或未登入不能存取。只顯示彙總與時間，不增加使用者錄音、文字或個人提示詞展示。

此版沒有外部離線告警。主機或網路完全中斷時，管理頁本身也可能無法開啟。頁面只在按重新整理或完成帳號操作後更新，需查看維護檢查時間。

帳號佇列的單筆 provider 呼叫現在有 240 秒整體期限，不包含排隊等待。即使對方持續傳送資料而沒有觸發 HTTP 閒置逾時，仍會取消等待，將工作標為失敗並釋放保留額度。原有 HTTP 100 秒逾時仍可能先發生。空白或只有空白字元的文字亦視為失敗，不交付或扣額度。手機原有三分鐘等待上限仍適用，逾時後可用「取回上一筆」查看伺服器狀態。

取消 API 等待不保證下游 GPU 工作已停止；本機推論服務若仍卡住，後續工作可能因 GPU 忙碌而失敗。此機制保護帳號佇列與額度，不能代替模型程序的健康監控與故障重啟。未加入自動重送，避免重複推論或扣量。

新增測試以卡住的非同步 provider 模擬第一筆工作，確認逾時取消、額度釋放、第二個帳號繼續完成；另測空字串及只有空白字元的結果不扣量。18 項帳號 API 測試通過，包括原有重啟恢復與重試行為。

驗證：完整測試 49 項通過後，新增的管理 API 權限與異常紀錄測試亦通過。以合成維護資料檢查 412px 手機畫面，六項狀態、過期提示及雲端未驗證文案正常，無水平溢出及 JavaScript 錯誤。這不是 Pixel 9 原生鍵盤實測。
