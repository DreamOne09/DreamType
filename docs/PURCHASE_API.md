# 手機購買 API

此路由可供付款版服務明確掛載，目前正式主機尚未啟用。必須共用錄音 Store 的明確付款政策；沒有政策時拒絕建立路由。

- GET /v2/billing/google/account：登入後回傳後端衍生帳號對應碼、商品／基本方案清單與每月 UTC 秒數。價格應由 Google Play 顯示，此 API 不自行定價。
- POST /v2/billing/google/verify：只接受 purchase_token。後端使用自己的時間查詢 Google、驗證歸屬、原子保存狀態，回傳目前政策下的方案、權益狀態及剩餘秒數。手機自報 paid 或其他欄位會被拒絕。

所有回應 no-store；錯誤不回傳憑證或 Google 原始回應。登入在讀取購買內容及供應商請求之前驗證，服務內另有查詢後與交易內重新驗證。

預設每程序共用每分鐘 30 次、同時 4 筆上限。JSON 不支援壓縮，最多 8 KiB，讀取期限 10 秒；聲明超量時不讀內容，串流仍逐塊檢查。手機取消不會終止已開始的同步查驗：該名額一直保留到真正完成，並保留工作參照與回收例外。

這是單程序的基本保護；多程序或公開大規模服務仍須配合邊緣限流與帳號級限制。付款供應商／憑證供應的期限仍由各自實作負責，不把讀取內容期限當作整筆交易期限。

測試以 ASGI HTTP 與合成 Google 回應串起手機請求、帳號綁定與實際額度政策，另外驗證取消後容量不提早釋放、超量與慢速上傳不觸發 Google。這不是 Android 商店或真實付款測試。
