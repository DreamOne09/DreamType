# 新口述意圖與時間改口案例

2026-09-28：新增六個合成文字案例，使用家用主機的真實整理模型，涵蓋請求句不執行、引用指令、條件否定、時間改口與例外、中英混用、保留問句。這不是語音辨識、Pixel 9 或 Typeless 比較測試。

首次結果有五例通過；「下午兩點，不對，改成下午三點」被忠實度檢查拒絕，回傳 503。既有改口規則只認得更正值不重複時段的形式，因此新增兩側都明確帶時段、單位相同的緊鄰改口。保留更正後的完整時段、數字及半點，仍拒絕模型改變這些值。引述及更複雜的分鐘寫法維持原文，不猜測修正。

修正後六例均回傳 200，人工檢查保留請求句、否定、條件與例外，沒有代寫計畫或回答問題。但時間改口案例多加一個條列符號，未通過單行要求，因此本組整體仍是 **5/6 通過**，不能把語意成功冒充排版成功。
