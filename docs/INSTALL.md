# 手機安裝：從下載到開始說話

1. 用 Chrome 點 repo 首頁「下載 Android APK」。在 Chrome → ⋮ → 下載，開啟下載的 DreamType 版本 APK。
2. 若 Android 要求，允許此瀏覽器安裝應用程式，再返回安裝。舊版直接更新，不需先刪除。
3. 開啟 DreamType，按「登入開始使用」。0.9.20 起會自動帶入經驗證的最新服務網址，再輸入管理者提供的 **帳號、密碼**。查詢失敗時，可按「取得最新服務網址」重試，或輸入管理者提供的 HTTPS 網址。不要把 GitHub 頁面網址填進服務欄位。
4. 返回首頁，允許麥克風，再按「啟用鍵盤」開啟 DreamType，保留 Gboard。
5. 在記事本的文字框切換 DreamType，按「開始說話 → 停止並整理 → 插入文字」。

登入與啟用完成後，平常不用開網頁。手機可以用行動網路，保持 Surfshark。

## 原本使用私人金鑰

更新保留原有設定。新手機可從首頁「帳號與連線 → 進階：私人電腦連線」填網址與金鑰，按「儲存並測試連線」，再回首頁啟用鍵盤。此模式仍只在手機保存偏好，不能把金鑰分享給多人。

## 設定、換機與更新

- 「我的設定」調整提示詞、常用詞與台灣地名參考；帳號模式儲存到主機。
- 新 Android 手機安裝並登入同一帳號，即取回偏好；舊手機可在「我的帳號 → 同步我的偏好」重新取回。自動插入的選擇仍由每支手機個別設定。
- 「我的帳號」可以查看額度、修改密碼、登出或刪除帳號。登入七天後需重新登入。
- 管理者更換臨時網址：0.9.20 起到「我的帳號 → 更新服務網址並重新登入」，取得最新網址後重新輸入帳密。帳號仍在原主機；有未完成錄音時先回鍵盤處理，重新登入成功會清除舊登入的暫存錄音。
- 「我的設定 → 檢查 App 更新」開啟 GitHub 下載新版。管理者發布的版本沿用同一簽章；自行編譯的憑證可能不同。

## 遇到問題

- 登入失敗：確認網址、帳密，或請管理者查看是否停用；不要把密碼貼到公開 issue。
- 連線失敗：管理者主機需開啟且未睡眠，臨時通道也需運行。
- 沒有帳號：目前由管理者邀請，GitHub 不會自動提供免費 AI 服務。
- 選不到鍵盤：先在 Android 鍵盤設定啟用，再到輸入框切換。
- 修改文字：先選 Gboard 編輯，再回原 App 切回 DreamType 插入。
- 網路中斷：帳號模式會重查結果，也可用「更多 → 取回上一筆」。原工作需已送達，结果暫存約 15 分鐘；不自動重送錄音。詳見 [恢復說明](RECOVERY.md)。

尚未支援 iPhone。原生 Pixel 9 操作仍待實機驗收，清單見 [BETA_ACCEPTANCE.md](BETA_ACCEPTANCE.md)。

0.6.0 帳號模式上傳失敗後，可按「重試上一段」；錄音會加密暫存一份，成功後清除，超過一小時不可重試。手動清除在「更多 → 刪除保留錄音」。登入／主機重啟限制見 [兩輪修正](TWO_ROUND_REVIEW.md)。

## 常用詞怎麼設定

「常用詞」放你希望正確辨識的名字，例如「東華大學、DreamType、板橋車站」。用逗號或換行分開，最重要的放前面，避免塞入整篇說明。這是辨識提示，不能保證每次都正確；錄音太遠、背景聲或同音詞仍可能認錯。

如果某個錯詞經常出現，另在「我的用詞建議」設定「錯詞 → 正確詞」。結果出現後到修改頁點選建議才會替換，也能復原。這兩個設定用途不同：前者幫助聽懂，後者協助你修字。帳號模式儲存後可同步到其他裝置。

回報錯字時，提供「常用詞設定、實際辨識文字、你原本想說的文字、錄音大約多久」，不必提供私人錄音或帳密。
