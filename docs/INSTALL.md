# 手機安裝：從下載到開始說話

1. 用 Chrome 開啟 repo 首頁的「下載 Android APK」。
2. Chrome → ⋮ → 下載 → 點 DreamType.apk。
3. 若系統要求，為這次下載所用的瀏覽器允許「安裝未知應用程式」，再返回安裝。
4. 開啟 DreamType →「01 連接電腦」。
5. 填入電腦啟動時提供的 HTTPS 網址與私人金鑰，按「儲存並測試連線」。不要填 GitHub 網址；GitHub 是下載位置，不是你的 AI 伺服器。
6. 「02 允許麥克風」→ 允許錄音。
7. 「03 啟用鍵盤」→ Android 鍵盤設定 → 開啟 DreamType。系統會顯示鍵盤的一般權限提醒。
8. 到記事本點輸入框，按系統鍵盤切換按鈕，選 DreamType。按「開始說話」，說完按「停止並整理」。

不想使用網頁：直接在 App 手動填網址與金鑰即可；日常使用完全不需要網頁。私人配對頁只是省去複製貼上的選項。

換手機：在新的 Android 重做上述步驟。換電腦：先跑 repo 安裝與啟動腳本，再用新的連線資料設定 App。iOS 版本尚未提供。

連不到電腦：確認電腦未睡眠、服務已啟動，並使用這次啟動產生的網址；臨時通道會改網址。
金鑰錯誤：重新複製完整金鑰，不要貼到公開 issue。
无法更新：官方 0.1.0 與 0.2.0 使用相同套件及憑證，應可覆蓋更新；自己編譯的憑證可能不同。
找不到鍵盤：先在 Android 鍵盤設定啟用，再到文字框切換。
