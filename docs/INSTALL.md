# 手機安裝：從下載到開始說話

1. 用 Chrome 點 repo 首頁「下載 Android APK」。在 Chrome → ⋮ → 下載，開啟 DreamType.apk。
2. 若 Android 要求，允許此瀏覽器安裝應用程式，再返回安裝。舊版直接更新，不需先刪除。
3. 開啟 DreamType，按「登入開始使用」。輸入管理者提供的 **HTTPS 服務網址、帳號、密碼**。不要填 GitHub 網址。
4. 返回首頁，允許麥克風，再按「啟用鍵盤」開啟 DreamType，保留 Gboard。
5. 在記事本的文字框切換 DreamType，按「開始說話 → 停止並整理 → 插入文字」。

登入與啟用完成後，平常不用開網頁。手機可以用行動網路，保持 Surfshark。

## 原本使用私人金鑰

更新保留原有設定。新手機可從首頁「私人電腦連線」填網址與金鑰，按「儲存並測試連線」，再回首頁啟用鍵盤。此模式仍只在手機保存偏好，不能把金鑰分享給多人。

## 設定、換機與更新

- 「我的設定」調整提示詞、常用詞與台灣地名參考；帳號模式儲存到主機。
- 新 Android 手機安裝並登入同一帳號，即取回偏好；舊手機可在「我的帳號 → 同步我的偏好」重新取回。自動插入的選擇仍由每支手機個別設定。
- 「我的帳號」可以查看額度、修改密碼、登出或刪除帳號。登入七天後需重新登入。
- 管理者更換臨時網址：先移除手機登入資料，再輸入新網址重新登入；帳號仍在原主機。
- 「我的設定 → 檢查 App 更新」開啟 GitHub 下載新版。正式發布的 0.1.0 至 0.4.0 使用同一簽章；自行編譯的憑證可能不同。

## 遇到問題

- 登入失敗：確認網址、帳密，或請管理者查看是否停用；不要把密碼貼到公開 issue。
- 連線失敗：管理者主機需開啟且未睡眠，臨時通道也需運行。
- 沒有帳號：目前由管理者邀請，GitHub 不會自動提供免費 AI 服務。
- 選不到鍵盤：先在 Android 鍵盤設定啟用，再到輸入框切換。
- 修改文字：先選 Gboard 編輯，再回原 App 切回 DreamType 插入。
- 網路中斷：目前不自動重送；不要連續提交多次。草稿不會永久保存。
